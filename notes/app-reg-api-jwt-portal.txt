Step 1.7: Configure Manifest for v2.0 Tokens (CRITICAL)

Left menu → Manifest
Click Download (optional - for backup)
Find this line in the JSON:

json   "accessTokenAcceptedVersion": null,

Change it to:

json   "accessTokenAcceptedVersion": 2,

Scroll down and find:

json   "api": {
       "requestedAccessTokenVersion": null,

Change it to:

json   "api": {
       "requestedAccessTokenVersion": 2,
```

7. Click **Save** at the top

**What this does:**
- Forces the API to issue **v2.0 tokens**
- v2.0 tokens return role **values** (like "Order.Admin")
- v1.0 tokens return role **IDs** (GUIDs) ← We don't want this!

## **Part 2: Create Client Application**

### **Step 2.1: Create Client App Registration**

1. Go back to **App registrations** (breadcrumb or search)
2. Click **+ New registration**
3. Fill in:
```
   Name: MyAppClient
   
   Supported account types:
   ● Accounts in this organizational directory only (Single tenant)
   
   Redirect URI:
   Platform: Public client/native (mobile & desktop)
   URI: http://localhost
```

4. Click **Register**

**What you'll see:**
- Page: "MyAppClient | Overview"
- **Application (client) ID**: e.g., `4ed5e537-6b4c-4c1a-b832-5de5c31b42f2`

5. **SAVE THIS VALUE:**
   - Application (client) ID: ________________________

---

### **Step 2.2: Configure for Public Client**

1. Left menu → **Authentication**
2. Scroll to **Advanced settings**
3. Find **"Allow public client flows"**
4. Toggle to **Yes**
5. Click **Save** at top

**What you'll see:**
```
Advanced settings:
  Allow public client flows: Yes ✓
```

---

### **Step 2.3: Add More Redirect URIs**

Still on "Authentication" page:

1. Under **Mobile and desktop applications**
2. Click **+ Add URI**
3. Add: `https://login.microsoftonline.com/common/oauth2/nativeclient`
4. Click **+ Add URI**
5. Add: `http://localhost:3000`
6. Click **+ Add URI**
7. Add: `http://localhost:8080`
8. Click **Save** at top

**Final result:**
```
Mobile and desktop applications
  4 Redirect URIs:
    http://localhost
    http://localhost:3000
    http://localhost:8080
    https://login.microsoftonline.com/common/oauth2/nativeclient

Step 2.4: Configure Manifest for v2.0 Tokens (CRITICAL)

Left menu → Manifest
Find this line:

json   "accessTokenAcceptedVersion": null,

Change it to:

json   "accessTokenAcceptedVersion": 2,

Find this section:

json   "api": {
       "requestedAccessTokenVersion": null,

Change it to:

json   "api": {
       "requestedAccessTokenVersion": 2,

Find this line:

json   "isFallbackPublicClient": null,

Change it to:

json   "isFallbackPublicClient": true,
```

8. Click **Save** at top

**What this does:**
- Client requests **v2.0 tokens** from the API
- Enables **public client flows** (device code flow)
```
